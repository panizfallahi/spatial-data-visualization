# Spatial Data Visualization and Analysis

## Overview

This project focuses on spatial data analysis and visualization using R.

The project explores geographic data of Iran, with a focus on administrative boundaries and the spatial distribution of cities in Alborz Province.

## Tools & Technologies

- R
- sf
- tmap
- ggplot2
- dplyr
- data.table
- Leaflet
- Spatial Data Analysis

## Project Highlights

- Reading and processing geographic data from Shapefile format
- Handling Coordinate Reference Systems (CRS)
- Filtering and analyzing geographic data
- Spatial data intersection and manipulation
- Visualization of administrative boundaries
- Visualization of city locations
- Interactive map visualization
- Geographic data exploration and analysis

## Visualizations

The project includes multiple spatial visualizations, including:

- Administrative boundary maps
- Thematic maps
- City distribution maps
- Bubble maps
- Interactive geographic maps
- Statistical and geographic visualizations
