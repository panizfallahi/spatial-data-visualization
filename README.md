# Spatial Data Visualization

## Overview

This project focuses on spatial data analysis and visualization using R.

The project uses geographic data of Iran to explore administrative boundaries and the spatial distribution of cities, with a focus on Alborz Province.

## Tools & Technologies

- R
- sf
- tmap
- dplyr
- data.table

## Project Highlights

- Reading and processing spatial data from Shapefile format
- Coordinate Reference System (CRS) handling
- Filtering geographic data for Alborz Province
- Spatial data intersection and manipulation
- Visualization of administrative boundaries
- Visualization of city locations
- Interactive map visualization
- Geographic labeling and map customization

## Results

The project produces interactive geographic visualizations that show administrative boundaries and the spatial distribution of cities in Alborz Province.
